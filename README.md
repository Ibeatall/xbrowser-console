# XBrowser Console privacy policy

The public privacy policy for **XBrowser Console**, published by **Rookie Publishing**.

- Policy: https://ibeatall.github.io/xbrowser-console/
- Contact: xbrowserconsolesupport@gmail.com

This repository contains only the privacy-policy website. It does not contain app source archives or release packages.

## Hosting

GitHub Pages serves the `docs/` directory on `main`. The page uses plain HTML and CSS, a local app icon, and no JavaScript, analytics, web fonts or external embedded assets. No build step or dependency installation is needed.

To preview locally, run `python -m http.server 8765 --bind 127.0.0.1 --directory docs` and open http://127.0.0.1:8765/.

## Updating the policy

Edit `docs/index.html` and update its effective/last-updated date when practices change. Keep the policy consistent with the released app and the publisher's actual handling of support email. Review local-data controls and third-party services when app features change. Push to `main` to publish through GitHub Pages.

The policy describes data practices; it does not establish Microsoft Store certification or completion of the app's remaining release checks.
